## Setup & Local Testing

1. Clone the repository:
```bash
git clone https://github.com/heorshey/heorshey-portfolio-en.git
cd heorshey-portfolio-en
```

2. Open in browser:
```bash
open index.html
# or use a local server
python -m http.server 8000
# then visit http://localhost:8000
```

## Deployment to GitHub Pages

1. Create a new repository on GitHub named `heorshey-portfolio-en`
2. Push this code:
```bash
git init
git add .
git commit -m "Initial commit: English portfolio website"
git branch -M main
git remote add origin https://github.com/heorshey/heorshey-portfolio-en.git
git push -u origin main
```

3. Enable GitHub Pages:
   - Go to Settings → Pages
   - Source: Deploy from branch
   - Branch: main, folder: / (root)
   - Save

4. Your site will be live at: `https://heorshey.github.io/heorshey-portfolio-en`
   (or use a custom domain if configured)
